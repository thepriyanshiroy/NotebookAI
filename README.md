# NotebookAI 🤖

An AI-powered student workspace to organize notes, upload PDFs, and generate intelligent summaries instantly.

## 🌐 Live Demo

🔗 [Coming Soon]

## ✨ What it does

- Sign up and log in securely
- Create notebooks and write notes inside sections
- Upload PDFs and preview them
- Generate AI summaries with one click
- Summaries are saved — no regeneration needed

## 🛠️ Built With

- **React + Vite + Tailwind CSS**
- **Supabase** — Auth, Database, Storage
- **Google Gemini AI** — PDF Summaries
- **Vercel** — Hosting

## 🔒 Security

- Row Level Security on all database tables
- Private file storage with signed URLs
- JWT-based authentication
- Minimum 12-character password policy

## 🚀 Run Locally

```bash
git clone https://github.com/yourusername/notebookai.git
cd notebookai
npm install
npm run dev
```

Add your `.env.local`:

```
VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
```
